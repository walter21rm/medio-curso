# Medio curso

Repositorio público de dos personas. El producto todavía no está definido. Lo que ya está listo es el arnés para trabajar en paralelo y la puerta que comprueba cada cambio.

## Qué hay hoy

- Guías para los agentes: [AGENTS.md](AGENTS.md) e [INVARIANTS.md](INVARIANTS.md).
- Una tarea, una rama, un pull request. El flujo está en [CONTRIBUTING.md](CONTRIBUTING.md).
- `npm run check` en local y en GitHub.
- El alcance, vacío a propósito, en [docs/product/ALCANCE.md](docs/product/ALCANCE.md).
- La aplicación correrá en AWS EC2 cuando el producto deje de estar pendiente. Ver [docs/infra/EC2.md](docs/infra/EC2.md).

## Comandos

Hace falta Node 22 o superior.

```text
npm run check
```

## Invitar a la otra persona

En GitHub: Settings → Collaborators → Add people. Con permiso de escritura puede crear ramas, hacer push y abrir pull requests.

El usuario de GitHub de quien invita se pasa en el chat para enviar la invitación desde aquí.
