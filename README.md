# Medio curso · Mostrador

Mini ERP de una comercializadora con un solo almacén. Dos personas, un repositorio público.

La parte A cierra inventario. La parte B cierra ventas, cartera y caja. Las specs están en [docs/sdd](docs/sdd/README.md).

## Comandos

Hace falta Node 22 o superior.

```text
npm install
npm run check
```

## Cómo se entra

Cada persona trabaja en su rama y abre un pull request. El esqueleto se revisa entre las dos. Inventario se mergea antes de apoyar ventas en ese `main`.
