# Puesta en marcha

Hace falta Node 22 o superior y git.

```text
git clone https://github.com/walter21rm/medio-curso.git
cd medio-curso
npm install
npm run check
```

`npm install` deja TypeScript para `npm run typecheck`. `npm run help` lista los objetivos permitidos.

La rama de trabajo sale de `main` actualizado. El push va a esa rama, no a `main`, y el cambio entra por pull request. Ver [CONTRIBUTING.md](../CONTRIBUTING.md).
